# CLAUDE.md

WooCommerce theme "TMT Shop" (`tmt-shop/`), ported from the web shop (Storefront module) of the Laravel app maytinhdian/quan-ly-cua-hang. The owner works in Vietnamese: user-facing text and docs in Vietnamese, code identifiers in English. Sold/shared to customers who only know WordPress admin, so everything a shop owner changes must be in the Customizer, never in code.

## Layout

- `functions.php` loads `inc/`: `options.php` (defaults `tmt_defaults()`, read with `tmt_opt('group.key')` = theme_mod `tmt_group_key`; list options are JSON, read with `tmt_opt_list()`), `setup.php` (supports, menus, assets, inline CSS vars), `template-tags.php`, `menu.php` (main menu, mega menu, nav effects), `home.php`, `customizer.php` + `customizer-controls.php` (repeater + sortable controls), and with WooCommerce `woocommerce.php` + `filters.php` (GET filters `hang[]`, `gia`, `con-hang`, `ts[attr]`, `sap-xep`).
- Every product grid calls `tmt_product_card()` (`template-parts/product/card.php`); never write another card.
- Home sections = `template-parts/home/<key>.php`, keys from `tmt_home_sections()`. `software` = app's licence section (tabs from `tmt_home_software_tabs()`, options `home.software_*`). The filter switch is `span.sf-sw`; never style a bare `.sf-sw` (the section uses that class).
- CSS `assets/css/theme.css` is copied from the app's storefront styles (same class names `sf-*`) plus a WP section at the end. JS: `assets/js/theme.js` (all pages), `assets/js/product.js` (product page, global Swiper).
- Cart + checkout = one page (cart redirects to checkout when not empty): `inc/checkout.php` (fields, shipping helpers, block pages → shortcodes), templates `woocommerce/checkout/form-checkout.php` + `review-order.php` + `cart/cart-empty.php`, styles `assets/css/checkout.css`, JS `assets/js/checkout.js`. Quantity/coupon controls submit the hidden forms `#tmt-qty-form` / `#tmt-coupon-form` via the `form=` attribute.
- Bank-transfer QR: `inc/payment-qr.php` only (VietQR payload + SVG via `inc/vendor/qrcode.php`, account = first WooCommerce BACS account); call `tmt_order_qr_box($order)`, never build VietQR content elsewhere. Order lookup: `inc/order-lookup.php` (`[tmt_tra_don]`). Product-page promo banners: Customizer `product.promos`, `inc/promos.php`, render with `tmt_promos($position)`.
- Vendored libraries live in `assets/vendor/` (no CDN except Google Fonts / Material Icons).
- The PC builder ("Xây dựng cấu hình") is the plugin `tmt-shop-tools/` (same repo), ported from the app's `app/Modules/PcBuilder` (web mode only): `includes/slots.php` (12 slots + accessory slots the owner adds in admin, option `tmt_pcb_extra_slots`, keys `x…`, `extra` flag, no rules; `tmt_pcb_add_software_slots()` adds Windows/Office/Diệt virus (keys `xwin`/`xoffice`/`xav`, admin button + demo data, demo remembers its keys in `tmt_demo_slots`); empty saved slots still guess categories by slug, spec keys = WooCommerce global attributes `pa_<key with ->`, aliases), `catalog.php` (parts from products/variations in slot categories, cached transient), `checker.php` (the 22 rules, keep in sync with the app's CompatibilityChecker), `builder.php` (shortcode `[tmt_len_cau_hinh]`, REST `tmt/v1/cau-hinh/*`, add-whole-build-to-cart with server re-check, presets, A5 print `?in-cau-hinh=`), `admin.php` (WooCommerce → Lên cấu hình). Never send stock numbers to the browser. The theme links to it through the filter `tmt_pc_builder_url`; pages opt into full width with the filter `tmt_page_wide`.
- Blog = "Mẹo vặt" (theme `inc/blog.php` + `template-parts/blog/list.php|single.php`, styles `assets/css/blog.css` with the app's `mv-*` classes, JS `assets/js/blog.js`): featured = sticky posts, tabs `?xem=doc-nhieu|video` (noindex), post meta `_tmt_video_url`, `_tmt_level`, `_tmt_products` (SKUs), `_tmt_views`, `_tmt_helpful` (vote via admin-post `tmt_vote`, cookies `tmt_seen` / `tmt_voted`). Search box = `tmt_blog_search()` (under Chủ đề, phone copy above the tabs); "Nhờ tiệm làm" CTA = `tmt_blog_ask($place)` / `tmt_blog_cta($place)`, 3 styles + texts in Customizer group `blog.cta_*`.
- Plugin also holds: `includes/requests.php` (CPT `tmt_request` "Yêu cầu khách": quote YC / survey KS / trial DT, numbers per type per month, public form via admin-post `tmt_req` with honeypot + rate limit, email to `tmt_req_email`; `tmt_req_needs_quote()` = product with empty price, the theme calls `tmt_req_quote_form()`), `includes/landing.php` (CPTs `tmt_solution` `/giai-phap/` and `tmt_software` `/phan-mem/`, all content in meta `_tmt_lp` described by `tmt_lp_schema()`, repeater meta box `assets/landing-admin.*`, templates `templates/landing*.php`, styles `assets/landing.css` `lp-*`), `includes/demo.php` (WooCommerce → Dữ liệu mẫu; everything created carries `_tmt_demo` so removal is exact), `includes/discontinued.php` (meta `_tmt_eol` / `_tmt_replacement`, sets catalog visibility hidden and remembers the old one in `_tmt_eol_vis`; theme calls `tmt_eol()` / `tmt_eol_box()`), `includes/gifts.php` (CPT `tmt_gift` "Quà tặng kèm", rules in meta `_tmt_gift`, `tmt_gift_sync()` adds gift cart lines with cart item key `tmt_gift` and price 0 on `woocommerce_before_calculate_totals`; theme calls `tmt_gift_box()` and `tmt_gift_line()`; never count gift lines as savings), `includes/intro.php` ("Giới thiệu nâng cao" blocks in meta `_tmt_intro`, port of the app's IntroBlocks; theme renders `template-parts/product/intro.php` + `assets/css/intro.css` from `tmt_intro_blocks()`), `includes/promotions.php` (CPT `tmt_promo` "Khuyến mãi": flash price with time + limit, customer-group price (user meta `tmt_group`), combo = negative cart fee; config in meta `_tmt_promo`, used count `_tmt_promo_used`; prices go through WooCommerce price filters so every place shows the same price; theme calls `tmt_km_box()` / `tmt_km_badge()`. Prefix `tmt_km_` because the theme's banner helpers own `tmt_promo_*`).
- Repair intake page (plugin `includes/repair-intake.php`, rewrite `/sua-may/` → `templates/repair-intake.php`, `assets/repair.css` `rin-*` + `repair.js` calculator): every fee is read only through `tmt_repair_fees()` (option `tmt_repair[...]`, Customizer section "Sửa máy: quy trình và phí"); the theme's home section `repair` (`template-parts/home/repair.php`) uses the same function, never type a fee in a template. Its form posts request type `sua-may` (number `SM`).
- Newsletter: plugin `includes/newsletter.php` (CPT `tmt_subscriber`, admin-post `tmt_nl`, JSON when `X-Requested-With`, CSV download); the theme footer shows the built-in form when the plugin is active, otherwise the widget area `footer-newsletter`. Paper-plane JS `assets/js/newsletter.js` (option `effects.nl_plane`). A form with an input named `action` shadows `form.action`: read `getAttribute('action')`.
- Images: plugin `includes/media.php` (option `tmt_media`): `wp_handle_upload` filter shrinks to `max` px, EXIF-rotates, saves WebP (strips EXIF); `wp_handle_upload_prefilter` + `add_attachment` name/alt images uploaded with a product `post_id`; Media → Ảnh sản phẩm (`tmt-anh`: by category, unused = not in id sets and file path not found in posts/postmeta/options/termmeta incl. JSON-escaped paths, cached 1 h); product edit drop/paste box `assets/media-admin.js` posts to `async-upload.php`.
- Add-to-cart animation: `inc/cart-fx.php` + `assets/js/cart-fx.js` (options `effects.cart_*`, inner markup `tmt_atc_inner()`); brand text effects: `tmt_brand_text()` + `assets/js/brand-fx.js` (options `effects.brand_*`). Ports of the app's storefront-cart-fx / storefront-brand-fx.
- Effects: card hover (incl. `tilt`) and cursor (`effects.cursor`, `<body data-fx-cursor>`) are Customizer settings; `assets/js/fx.js` (port of the app's storefront-fx.js) loads only when tilt or a cursor is on.

## Testing

No build step. Lint with `php -l`, then run a WordPress + WooCommerce site with the theme active and check pages with WP_DEBUG on (no notices) and Playwright screenshots at desktop and phone width.
